\sectiontitle{13}{Selected theorem statements: unproved}
The original notes report 47 \texttt{Conjecture}s in
\texttt{OpenSignaturesTheorems.v}. No Rocq files are included here.
The statements below retain that unproved status; source soundness is
reformulated for the new judgment. Example typing and derived-rule claims
are also unproved. No equivalence or completeness theorem for the two
presentations is asserted.
\[
\begin{array}{@{}ll@{}}
 \text{Context validity}&
 \Gamma\vdash t:A\ \Longrightarrow\ \Gamma\ \op{wf}.\\[4pt]
 \text{Type correctness}&
 \Gamma\vdash t:A\ \Longrightarrow\ \exists k.\ \Gamma\vdash A:\Set_k.\\[4pt]
 \text{Weakening}&
 \Gamma\vdash t:A,\ \Gamma\vdash B:\Set_k
 \ \Longrightarrow\ \Gamma,x:B\vdash t:A.\\[4pt]
 \text{Substitution}&
 \Gamma,x:A\vdash t:B,\ \Gamma\vdash u:A
 \ \Longrightarrow\ \Gamma\vdash t[u/x]:B[u/x].\\[4pt]
 \text{Preservation}&
 \Gamma\vdash t:A,\ t\to u
 \ \Longrightarrow\ \Gamma\vdash u:A
 \quad\text{(also for }\leadsto\text{).}\\[4pt]
 \text{Progress}&
 \varnothing\vdash t:A
 \ \Longrightarrow\ \op{value}(t)\ \lor\ \exists u.\ t\to u.\\[4pt]
 \text{Normalization}&
 \Gamma\vdash t:A\ \Longrightarrow\ t\text{ is strongly normalizing for }\leadsto.\\[4pt]
 \text{Confluence}&
 \Gamma\vdash t:A,\ t\leadsto^*u,\ t\leadsto^*v\\
 &\hspace{6mm}\Longrightarrow\ \exists w.\ u\leadsto^*w\land v\leadsto^*w.\\[4pt]
 \text{Consistency}&
 \neg\exists t.\ \varnothing\vdash t:\bot.\\[4pt]
 \text{Dead soundness}&
 \dead{D}{X}{d}\ \Longrightarrow\ \Gamma\vdash d:\interp{D}{X}\to\bot.\\[4pt]
 \text{Description soundness}&
 \dsub{D}{D'}{X}{q}\ \Longrightarrow\
 \Gamma\vdash q:\interp{D}{X}\to\interp{D'}{X}.\\[4pt]
 \text{Coercion soundness}&
 \subt{A}{B}{c}\ \Longrightarrow\ \Gamma\vdash c:A\to B.\\[4pt]
 \text{Elaboration soundness}&
 \elab{e}{A}{t}\ \Longrightarrow\ \Gamma\vdash t:A.\\[4pt]
 \text{Coercion coherence}&
 \subt{A}{B}{c},\ \subt{A}{B}{d}
 \ \Longrightarrow\ c\approx_{A\to B}d.\\[4pt]
 \text{Roll/unroll}&
 \Gamma\vdash x:C_{F,G}(i)
 \ \Longrightarrow\ \roll(\unroll_{F,G,i}\,x)\approx_{C_{F,G}(i)}x.
\end{array}
\]
The last statement additionally requires
$\Gamma\vdash I:\Set_0$, $F,G:\Defs\,I$, and $i:I$.
Weakening uses a fresh $x$.
$\approx_A$ quantifies over typed closing substitutions and closed Boolean
observations. It is not definitional equality.
\[
\begin{gathered}
 \Gamma\vdash A:\Set_0
 \ \Longrightarrow\
 \subt{\op{NonEmpty}\,A}{\op{List}\,A}{\op{toList}},\\
 \neg\exists c.\ \varnothing\vdash c:
       \Pi A:\Set_0.\,\op{List}\,A\to\op{NonEmpty}\,A,\\
 \varnothing\vdash A:\Set_0
 \ \Longrightarrow\
 \neg\exists x.\ \varnothing\vdash x:C_{U_A,U_A}(\unit).
\end{gathered}
\]
The original notes report ten closed computation checks proved by
reflexivity in \texttt{OpenSignaturesExamples.v}. These do not prove the
general typing claims or the revised elaboration soundness statement.

\textbf{Why unrestricted source elaboration is not unconditionally coherent.}
The former checking-coherence statement cannot simply be renamed. In this
core syntax, an unannotated rolled value can have different types whose
coercions into a common type retag it differently.
Take $I=\one$, distinct literal identities $a,b$, and the closed rows
\[
\begin{aligned}
 r_a&=[(a,\code{\one})],&
 r_b&=[(b,\code{\one})],&
 r_{ab}&=[(a,\code{\one}),(b,\code{\one})],\\
 F_a&=\lambda i.\,\rows{r_a},&
 F_b&=\lambda i.\,\rows{r_b},&
 G&=\lambda i.\,\rows{r_{ab}}.
\end{aligned}
\]
Let $A_a=C_{F_a,G}(\unit)$, $A_b=C_{F_b,G}(\unit)$,
$T=C_{G,G}(\unit)$, and $v=\roll(0,\unit)$. With $\Gamma=\varnothing$,
\[
 \jd{v}{A_a},\qquad \jd{v}{A_b},\qquad
 \subt{A_a}{T}{c_a},\qquad \subt{A_b}{T}{c_b}.
\]
Here $c_a$ uses the live handler $\op{retag}_0$, while $c_b$ uses
$\op{retag}_1$. Applying \texttt{el\_core} and \texttt{el\_sub} gives
\[
 \elab{\op{core}(v)}{T}{c_a\,v},\qquad
 \elab{\op{core}(v)}{T}{c_b\,v},
\]
with different observable constructor tags:
\[
 c_a\,v\leadsto^*\roll(0,\unit),\qquad
 c_b\,v\leadsto^*\roll(\op{s}\,0,\unit).
\]
A $\op{closeCase}$ observer can return distinct Boolean values for the
$a$ and $b$ branches. Thus the unrestricted relation does not satisfy
\[
 \elab{e}{A}{t},\ \elab{e}{A}{u}
 \quad\Longrightarrow\quad t\approx_A u
\]
in general. This counterexample is a derivation-level argument, not a
machine-checked proof. It does not refute coercion coherence for \emph{fixed}
endpoints: the two coercions above have different source types.
A coherent implementation would need additional restrictions or a specified
resolution discipline. Merely placing an outer annotation on
$\op{core}(v)$ does not remove this ambiguity, because \texttt{el\_sub} can
still occur inside the annotation premise.

\textbf{Relation to the original development.}
The unchanged core computations, descriptions, row coercions, and common
recursive definition in \texttt{su\_close} are retained. The source rules
and live-clause premise have changed; no corresponding Rocq update or
proof port is claimed.
